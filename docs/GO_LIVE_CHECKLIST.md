# Go-Live Checklist

ไล่ทำตามนี้ก่อนเริ่มใช้งานแทนระบบเดิมจริงจัง

## ก่อน Go-Live

- [ ] ทำตาม `UAT_CHECKLIST.md` ครบทุกข้อ ไม่มี error
- [ ] เปลี่ยนรหัสผ่าน `admin` จากค่าเริ่มต้นแล้ว
- [ ] ตั้งค่าข้อมูลบริษัท (ชื่อ/ที่อยู่/เบอร์โทร/เลขผู้เสียภาษี) ที่หน้า
      "ข้อมูลบริษัท" ครบถ้วน — จะไปโชว์บนทุกเอกสารที่พิมพ์
- [ ] ตั้งค่า VAT Rate ให้ถูกต้อง (7% หรือค่าปัจจุบัน ณ วันที่ Go-Live)
- [ ] นำเข้าข้อมูลลูกค้า/สาขา/สินค้าจากระบบเดิมผ่าน Excel Import ครบถ้วน
      (ตรวจสอบจำนวนแถวที่ import สำเร็จให้ตรงกับข้อมูลต้นทาง)
- [ ] นำเข้าราคา/ส่วนลดพิเศษของลูกค้าแต่ละราย (ถ้ามี) ให้ครบ
- [ ] พิมพ์เอกสารทดสอบบนเครื่องพิมพ์จริง (EPSON LQ-310 + กระดาษต่อเนื่อง)
      แล้วตรวจตำแหน่งให้แม่นยำ — ปรับ `src/lib/print-settings.ts` ถ้ายังไม่
      ตรง
- [ ] ตั้งค่า Backup อัตโนมัติทุกวันแล้ว (Task Scheduler)
- [ ] ทดสอบ Restore จาก Backup ได้จริง (ทำบนเครื่องทดสอบ ไม่ใช่เครื่องจริง)
- [ ] สร้าง User สำหรับพนักงานทุกคนที่ต้องใช้งานจริง กำหนด Role ให้ถูกต้อง
- [ ] พนักงานทุกคนอ่าน/ทำความเข้าใจ `USER_GUIDE.md` แล้ว
- [ ] ตั้งค่าระบบให้รันอัตโนมัติเมื่อเปิดเครื่อง (PM2 หรือเทียบเท่า)
- [ ] สร้าง Desktop Shortcut ให้พนักงานเปิดใช้งานง่าย

## วัน Go-Live

- [ ] เริ่มคีย์ Order แรกในระบบใหม่ ตรวจสอบทุกขั้นตอนละเอียด (Preview →
      Confirm → พิมพ์บิล → ตรวจตัวเลขให้ถูกต้อง)
- [ ] เก็บระบบเดิมไว้เป็น read-only สำรอง (อย่าเพิ่งปิด/ลบทิ้ง) อย่างน้อย
      1-2 เดือนแรก เผื่อต้องอ้างอิงข้อมูลเก่า

## หลัง Go-Live (สัปดาห์แรก)

- [ ] เช็ค Audit Log ทุกวันดูว่ามีอะไรผิดปกติไหม
- [ ] เช็ค System Logs ดู Error ที่เกิดขึ้นจริง
- [ ] เก็บ Feedback จากพนักงานที่ใช้งานจริง ว่าจุดไหนติดขัด
- [ ] ตรวจว่า Backup อัตโนมัติทำงานจริงทุกวัน (ดูที่หน้า "สำรอง/กู้คืนข้อมูล")

## Rollback Plan (ถ้าจำเป็น)

ถ้าเจอปัญหาร้ายแรงจนใช้งานต่อไม่ได้ ให้กลับไปใช้ระบบเดิมชั่วคราว แล้วแจ้ง
ปัญหาที่เจอเพื่อแก้ไข — ข้อมูลที่คีย์ไปแล้วในระบบใหม่ยังอยู่ครบ (ไม่หาย)
สามารถกลับมาทำต่อได้หลังแก้ปัญหาเสร็จ
