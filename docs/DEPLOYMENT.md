# คู่มือติดตั้งใช้งานจริง (Deployment Guide)

เขียนให้อ่านง่ายที่สุด สำหรับคนที่ไม่ถนัดคอมพิวเตอร์ — ให้ช่างไอทีหรือ
Claude Code เป็นคนลงมือทำตามนี้

## ภาพรวมก่อน: มันทำงานยังไง

ระบบนี้ **ไม่เหมือนเว็บไซต์ทั่วไปที่ต้องเช่าโดเมน/โฮสติ้ง** เพราะออกแบบให้
รันอยู่ **ในเครื่องคอมพิวเตอร์ของบริษัทเอง** (เครื่องที่ใช้ทำบิลประจำ) แล้ว
เปิดผ่าน browser (Chrome/Edge) ในเครื่องนั้น เหมือนเปิดโปรแกรมทั่วไป —
ไม่ต้องเสียค่าเช่าโดเมน ไม่ต้องพึ่งอินเทอร์เน็ตเลย (ยกเว้นถ้าอนาคตอยากเปิด
ให้เข้าถึงจากนอกบริษัทถึงจะต้องคิดเรื่องนี้เพิ่ม — ไม่จำเป็นตอนนี้)

## สิ่งที่ต้องเตรียม

1. เครื่องคอมพิวเตอร์ 1 เครื่อง (Windows) ที่จะใช้เป็นเครื่องทำบิลหลัก
   สเปกไม่ต้องแรงมาก แต่แนะนำ RAM 8GB ขึ้นไป
2. คนที่ทำตามขั้นตอนด้านล่างได้ (ช่างไอที หรือ Claude Code)

## ขั้นตอนติดตั้ง (ทำครั้งเดียว)

### ขั้นที่ 1: ติดตั้งโปรแกรมพื้นฐาน

ติดตั้ง 2 โปรแกรมนี้ในเครื่อง (ดาวน์โหลดฟรี):

- **Node.js** (เวอร์ชัน 20 หรือใหม่กว่า) — https://nodejs.org
- **PostgreSQL** (เวอร์ชัน 16) — https://www.postgresql.org/download/windows/
  ตอนติดตั้งจะให้ตั้งรหัสผ่าน — **จดรหัสผ่านนี้ไว้ให้ดี** จะใช้ในขั้นตอนถัดไป

### ขั้นที่ 2: เอาโค้ดเข้าเครื่อง

นำไฟล์โปรเจกต์ (ที่ได้รับจาก Claude) ไปวางในเครื่อง เช่นที่
`C:\bill-system`

### ขั้นที่ 3: ตั้งค่าเชื่อมต่อฐานข้อมูล

เปิด Command Prompt ในโฟลเดอร์โปรเจกต์ แล้วรัน:

```
npm install
copy .env.example .env
```

เปิดไฟล์ `.env` ด้วย Notepad แก้บรรทัด `DATABASE_URL` ให้ใส่รหัสผ่านที่
จดไว้ตอนติดตั้ง PostgreSQL เช่น:

```
DATABASE_URL="postgresql://postgres:รหัสผ่านที่ตั้งไว้@localhost:5432/bill_system"
```

แก้ `NEXTAUTH_SECRET` และ `BACKUP_SECRET` เป็นค่าสุ่มยาวๆ (จะเป็นตัวอักษร/
ตัวเลขอะไรก็ได้ ยิ่งยาวยิ่งปลอดภัย)

### ขั้นที่ 4: สร้างฐานข้อมูลและข้อมูลเริ่มต้น

```
npm run prisma:migrate -- --name init
npm run prisma:seed
```

จะได้ User แรก: `admin` / `ChangeMe123!` — **เปลี่ยนรหัสผ่านทันทีหลัง Login
ครั้งแรก** (ผ่าน Prisma Studio รอ User Management UI เต็มรูปแบบใน Version
ถัดไป)

### ขั้นที่ 5: Build และรันระบบจริง

```
npm run build
npm run start
```

เปิด browser ไปที่ `http://localhost:3000` — ควรเห็นหน้า Login

### ขั้นที่ 6: ทำให้ระบบรันอัตโนมัติทุกครั้งที่เปิดเครื่อง

ถ้าต้องปิด Command Prompt ระบบจะหยุดทำงาน — แนะนำให้ติดตั้งเป็น Windows
Service ด้วยโปรแกรมชื่อ **PM2**:

```
npm install -g pm2
pm2 start npm --name "bill-system" -- start
pm2 save
pm2-startup install
```

วิธีนี้ระบบจะรันอยู่เบื้องหลังตลอด แม้ปิด Command Prompt หรือรีสตาร์ทเครื่อง

### ขั้นที่ 7: สร้างไอคอนเปิดใช้งานง่ายๆ

สร้าง Shortcut บน Desktop ชี้ไปที่ `http://localhost:3000` (คลิกขวาที่
Desktop → New → Shortcut → พิมพ์ URL) พนักงานจะได้ดับเบิลคลิกเปิดได้เลย
เหมือนเปิดโปรแกรมปกติ

### ขั้นที่ 8: ตั้งค่า Backup อัตโนมัติ

ดูขั้นตอนใน `README.md` หัวข้อ "Backup อัตโนมัติ" (ใช้ Windows Task
Scheduler เรียก URL พิเศษทุกวัน)

## ถ้าอยากให้เครื่องอื่นในบริษัทใช้ด้วย (อนาคต)

ตามที่ตกลงกันไว้ ระบบออกแบบให้ขยายไป Database กลางได้โดยไม่ต้องเขียนใหม่ —
แค่ย้าย PostgreSQL ไปอยู่เครื่องแม่ข่ายกลาง แล้วแก้ `DATABASE_URL` ในเครื่อง
ทุกเครื่องให้ชี้ไปที่เครื่องนั้นแทน `localhost` (ขั้นตอนนี้ต้องมีคนที่มี
ความรู้ IT ช่วยตั้งค่า Network ให้ถูกต้อง — แจ้งได้เมื่อพร้อมทำ)

## ถ้าอยากเปิดให้เข้าถึงจากนอกบริษัท (อนาคต ไม่แนะนำตอนนี้)

การเปิดระบบออกสู่อินเทอร์เน็ตต้องพิจารณาเรื่องความปลอดภัยเพิ่มเติมมาก
(Firewall, HTTPS, การป้องกันการโจมตี ฯลฯ) แนะนำให้ปรึกษาผู้เชี่ยวชาญด้าน
ความปลอดภัยก่อนทำ ไม่แนะนำให้เปิดเองโดยไม่มีความรู้เฉพาะทาง
