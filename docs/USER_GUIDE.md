# คู่มือใช้งานประจำวัน — พนักงานออกบิล

## เข้าสู่ระบบ

เปิดไอคอนระบบออกบิลบน Desktop → กรอกชื่อผู้ใช้/รหัสผ่านที่ได้รับ

## ขายของ 1 ครั้ง ทำยังไง (Flow หลักที่ใช้ทุกวัน)

1. เมนู **"ออเดอร์ขาย"** → กด **"+ สร้างออเดอร์ใหม่"**
2. เลือกลูกค้า → เลือกสาขา → ตรวจวันที่ (ปกติเป็นวันนี้อยู่แล้ว) → กด
   **"สร้างออเดอร์ → ไปคีย์รายการสินค้า"**
3. หน้าคีย์สินค้า: พิมพ์ **SKU หรือชื่อสินค้า** ในช่องค้นหา → กดลูกศร
   ขึ้น/ลงเลือกสินค้า หรือกด Enter เลย → ใส่ **จำนวน** → กด Enter หรือปุ่ม
   "+ เพิ่มรายการ"
4. ทำซ้ำข้อ 3 จนครบทุกสินค้าที่ลูกค้าสั่ง (สินค้าคนละประเภทกันคีย์ปนกัน
   ในออเดอร์เดียวได้เลย ระบบจะแยกบิลให้เองอัตโนมัติ)
5. ดูช่อง **"สรุปแยกตามประเภทสินค้า (Preview)"** ด้านล่าง — ตรวจสอบราคา/
   ส่วนลด/ยอดรวมให้ถูกต้องก่อน
6. ถ้าถูกต้องแล้ว กด **"✓ Confirm ออเดอร์"** — ระบบจะสร้างบิลแยกให้เองตาม
   ประเภทสินค้าทันที (เช่น มี 3 ประเภท จะได้ 3 บิล)

## พิมพ์บิลให้ลูกค้า

- เปิดที่เมนู **"ใบส่งของ/บิล"** → คลิกเลขที่บิลที่ต้องการ → กด
  **"พิมพ์เอกสาร"** → กด **"พิมพ์ / บันทึกเป็น PDF"**

## ลูกค้าขอใบกำกับภาษี

- **ถ้าขอ VAT เต็มยอด**: เปิดบิล (Invoice) ที่เกี่ยวข้อง → กด **"สร้างใบ
  กำกับภาษีจากใบนี้ (VAT 100%)"**
- **ถ้าลูกค้าแจ้งรายการ/ยอดมาเอง**: เมนู **"ใบกำกับภาษี"** → **"+ สร้างใบ
  กำกับภาษี (เลือกรายการเอง)"** → กรอกรายการตามที่ลูกค้าแจ้ง

## ยกเลิกรายการ

- **ยกเลิกออเดอร์**: เปิดออเดอร์ → กด "ยกเลิกออเดอร์" (ถ้ามีบิลออกไปแล้ว
  ต้องยกเลิกบิลให้หมดก่อนถึงจะยกเลิกออเดอร์ได้)
- **ยกเลิกบิล**: เปิดบิล → กด "ยกเลิก Invoice ใบนี้"

## ถ้าคีย์ออเดอร์ผิด/อยากทำออเดอร์คล้ายเดิม

- เปิดออเดอร์เก่าที่ใกล้เคียง → เลื่อนลงล่างสุด → เลือกวันที่ใหม่ → กด
  "คัดลอก" — ระบบจะสร้างออเดอร์ใหม่ให้พร้อมรายการสินค้าเดิม (ราคา/ส่วนลด
  จะคำนวณใหม่ตามวันที่ปัจจุบันให้เองอัตโนมัติ)

## ค้นหาบิลเก่า

- เมนู "ใบส่งของ/บิล" หรือ "ออเดอร์ขาย" — คลิกดูรายละเอียดได้เลย
